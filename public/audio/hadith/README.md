## 🎧 Features

### Audio Player dengan Speed Controls

Audio player di app sudah dilengkapi dengan:
- ▶️ Play/Pause button
- 🔄 Restart button
- ⏱️ Progress bar
- 🎚️ Speed controls: **0.25x, 0.5x, 0.75x, Normal (1x)**
  - Cocok untuk pembelajaran bertahap
  - Anak-anak bisa mulai dari speed pelan (0.25x) untuk pelafalan yang jelas
  - Bertahap ke speed normal setelah familiar

---

## 📋 File Specifications

- Format: MP3
- Naming: Nama Arab sesuai teks hadist
- Quality: High quality recording
- Duration: 5-15 seconds per hadith
- Suitable for: Children learning (clear pronunciation)
